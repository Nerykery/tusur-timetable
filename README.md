# 📅 Расписание ТУСУР

Android-приложение для расписания Томского госуниверситета систем управления и радиоэлектроники.
Отвечает на два вопроса: **что идёт сейчас** и **куда идти дальше**.

Неофициальный клиент: данные берутся с сайта расписания [timetable.tusur.ru](https://timetable.tusur.ru).
Приложение не связано с ТУСУР.

## Возможности

**Расписание**
- Группа (по номеру, например `023` или `436-1`) и преподаватель (по фамилии).
- Неделя с переключением вперёд/назад, выбор дня пн–вс, кнопка «Сегодня».
- Подзаголовок с диапазоном дат и чётностью недели.
- Статус-блок: «Идёт 3-я пара · ещё 25 мин» с прогрессом, «Следующая через 1 ч 10 мин»,
  «Пары на сегодня закончились».
- Лента дня: время, номер пары, дисциплина, тип занятия, аудитория, этаж, преподаватели.
- Перерывы (≤ 30 мин) и «окна» (> 30 мин) между парами.
- Прошедшие пары приглушены, текущая обведена.
- Пустой день: «В этот день пар нет» и кнопка к ближайшему дню с занятиями.
- Цветовая кодировка типов занятий, подписи типов (не только цвет).
- Переход с преподавателя на его расписание и с группы на её расписание.

**Данные**
- Офлайн-режим: последняя неделя и справочник доступны без сети, с плашкой «данные от HH:MM».
- Сначала показывается кэш, затем фоновое обновление.
- Устойчивость к недоступности API: ретраи с backoff, человеческие тексты ошибок,
  возможность переключить источник на официальный `api.tusur.ru`.
- Время считается по **Asia/Tomsk (UTC+7)** независимо от пояса устройства.

**Напоминания (локальные, без сервера)**
- За N минут до пары (5/10/15/20/30, по умолчанию 15).
- Вечерняя сводка на завтра и утренняя на сегодня, с выбором часа.
- Общий тумблер уведомлений.
- Точные будильники через `AlarmManager`; без разрешения — честное предупреждение в настройках.
- Восстановление будильников после перезагрузки, защита от дублей.

**Схема корпуса ФЭТ**
- Этажи 0–4, pinch-to-zoom и кнопки масштаба.
- Поиск аудитории, нижний лист с занятостью по парам.
- Данные из `/api/load`: «Свободна до 15:00», «Занята до 14:50», «Нет в расписании корпуса».
- Схема рисуется по данным (`assets/fet.json`), а не картинкой.

**Виджеты** — четыре, для домашнего экрана (см. [таблицу](#виджеты)).

**Прочее**
- Светлая, тёмная и системная тема, dynamic color на Android 12+.
- Deep links на день, группу, преподавателя и схему корпуса.
- Крупные тач-таргеты, семантика для TalkBack, поддержка масштаба шрифта.

## Сборка

Требования: JDK 17+, Android SDK с `platforms;android-35` и `build-tools;35.0.0`.

```bash
# путь к SDK
echo sdk.dir=C\:\\Users\\<you>\\AppData\\Local\\Android\\Sdk > local.properties

# debug
./gradlew :app:assembleDebug

# release (R8 + shrinkResources; подписывается ключом app/tusur-release.jks, если он есть)
./gradlew :app:assembleRelease

# тесты
./gradlew :app:testDebugUnitTest
./gradlew :app:connectedDebugAndroidTest   # нужен эмулятор или устройство

# качество
./gradlew :app:lintDebug detekt
```

Свой базовый URL API без правки кода:

```bash
./gradlew :app:assembleDebug -Ptimetable.baseUrl=https://example.org/
```

Ключ подписи в репозиторий не входит (`*.jks` в `.gitignore`). Если файла нет, release собирается
без подписи — установить его на устройство нельзя, но сборка проходит.

## Разрешения

| Разрешение | Зачем |
|---|---|
| `INTERNET`, `ACCESS_NETWORK_STATE` | расписание и занятость аудиторий |
| `POST_NOTIFICATIONS` (Android 13+) | напоминания и сводки |
| `SCHEDULE_EXACT_ALARM` (Android 12+) | точное время; без него — неточный режим с предупреждением |
| `RECEIVE_BOOT_COMPLETED` | пересборка будильников и виджетов после перезагрузки |
| `WAKE_LOCK` | доставка напоминаний в простое |

## Виджеты

| Виджет | Размер | Что показывает |
|---|---|---|
| Следующая пара | 2×2 | «Идёт N-я пара · ещё X мин» или «Следующая через …», дисциплина и аудитория |
| Сегодня | 4×2 | до 5 пар на сегодня, «+N ещё», «Сегодня пар нет» |
| Неделя | 4×4 | пн–сб: число и количество пар, выделение сегодня; шире 280 dp — 3 колонки, иначе список |
| Быстрый выбор | 2×2 | своё расписание и режим «сегодня / следующая пара», настройка через config activity |

Обновление: WorkManager раз в 30 минут (страховка) и немедленно при старте приложения, смене
расписания, успешной загрузке, добавлении виджета, а также по `BOOT_COMPLETED`, `TIME_SET`,
`TIMEZONE_CHANGED`, `DATE_CHANGED`. Виджеты читают только кэш Room и не ходят в сеть из composition.
Посекундный отсчёт не обещается: «ещё N мин» обновляется по расписанию WorkManager.

## Архитектура

- **Слои.** `data` (сеть, Room, DataStore, репозитории) → `domain` (модели и чистые функции) → `ui`
  (Compose, ViewModel). UI не знает про Retrofit и Room.
- **Однонаправленный поток.** ViewModel держит `StateFlow<UiState>`; экран только рендерит и шлёт события.
- **Источники взаимозаменяемы.** `ScheduleRemoteSource` скрывает детали API: переключение
  источника — настройка, а не правка UI.
- **Offline-first.** Репозиторий сначала отдаёт кэш из Room, затем обновляет неделю. TTL 5 минут
  в памяти, на диске — дата загрузки.
- **Время.** Все вычисления «сейчас» идут через `TomskTime`, поэтому смена пояса устройства
  не ломает «идёт пара».
- **Побочные эффекты в одном месте.** `RefreshCoordinator` обновляет виджеты и пересобирает
  будильники после успешной загрузки.

## Ограничения

- Приложение неофициальное, API может измениться. Он изолирован в одном слое, базовый URL
  меняется параметром сборки.
- Официальный `api.tusur.ru` не имеет поиска и ищет преподавателя по фамилии — переход на
  преподавателя работает, только если фамилия известна из поиска или ссылки.
- Glance не поддерживает `font-feature-settings`, поэтому табличные цифры включены только в приложении.
- Виджеты не дают посекундный отсчёт: «ещё N мин» обновляет��я WorkManager раз в 30 минут.
- Схема корпуса примерная и не заменяет указатели в здании.
- Скриншот-тесты (Roborazzi/Paparazzi) не подключены: без эталонных изображений они дают шум.
